# 媒花录隐私政策

更新日期：2026年7月21日  
生效日期：2026年7月21日  

「媒花录」（以下简称「本应用」）由【运营主体全称】（以下简称「我们」）运营。我们深知个人信息对您的重要性，将按法律法规要求保护您的个人信息。

请在使用本服务前仔细阅读本《隐私政策》。您使用或继续使用本服务，即表示您理解并同意我们按本政策处理相关信息。

## 一、我们如何收集和使用个人信息

我们遵循合法、正当、必要和诚信原则，仅在实现产品功能所必需的范围内处理个人信息。

### 1.1 账号注册与登录

（1）手机号、短信验证码、登录密码：用于注册、登录与账号安全验证；  
（2）微信授权信息（如微信 OpenID/UnionID、昵称、头像等，以微信实际授权范围为准）：用于微信登录及账号绑定；  
（3）个人资料（昵称、头像等）：用于展示与账号管理。

### 1.2 拍照、录像与水印功能

（1）在您使用拍照/录像时，需要访问相机、麦克风权限以完成采集；  
（2）您主动拍摄或导入的照片、视频及您设置的水印文字、模板、时间戳等内容，用于生成本地成片、预览与编辑；  
（3）如您开启防伪相关功能，可能基于设备标识、图像摘要、时间及您授权的位置信息生成防伪码或验真凭证，并写入文件元数据。

### 1.3 位置信息

当您开启定位或使用需要地址水印、地图展示、轨迹/距离统计、上传位置参数等功能时，我们会在获得您授权后收集精确或大致位置信息（可能通过系统定位及高德等定位服务获取），用于水印展示、EXIF 写入、同步上传及验真相关能力。您可在系统设置中关闭定位权限，关闭后上述依赖定位的功能将受限。

### 1.4 相册与存储

为保存成片到系统相册（如「媒花录」相册）、读取本应用相关相册内容以进行水印编辑/去除、选择头像或上传素材，我们需要申请相册/媒体访问与写入相关权限。我们不会在未经您同意的情况下读取与业务无关的私人相册内容。

### 1.5 云同步、个人空间与团队空间

如您登录并开启同步或主动上传，我们会将您选择的媒体文件、文件哈希、拍摄时间、位置/地址文案、水印与防伪相关元数据、所属空间信息等上传至服务器，用于存储、展示、检索、团队协作与验真。团队空间中的内容可能对具备权限的团队成员可见，具体以团队管理设置为准。

### 1.6 图像识别与 OCR（如您使用）

当您使用图像标签识别、LED/屏幕文字识别等功能时，相关图片可能被发送至合作的云识别服务进行处理，以返回识别结果。该处理以实现您主动发起的功能为目的。

### 1.7 会员与支付

当您购买会员或付费服务时，可能收集订单号、商品信息、支付状态等；支付账号等敏感支付信息由微信支付、支付宝等持牌机构处理，我们一般仅接收支付结果，不收集您的完整银行卡号与支付密码。

### 1.8 设备与日志信息

为保障服务安全与质量，我们可能收集设备型号、操作系统版本、唯一设备标识（如 Android ID 等，以系统与合规要求为准）、网络类型、崩溃日志、操作日志、应用版本号等。用于故障排查、安全风控与体验优化。

### 1.9 征得同意的例外

根据相关法律法规，在以下情形中处理个人信息无需征得您的同意：为订立或履行合同所必需；为履行法定义务所必需；为应对突发公共卫生事件或紧急情况下保护自然人生命健康；在合理范围内处理您自行公开或其他已合法公开的信息；法律法规规定的其他情形。

## 二、我们如何使用 Cookie 与同类技术

本应用主要为移动客户端。如涉及 WebView 或网页组件，可能使用本地存储、Cookie 或同类技术用于登录态、偏好设置与安全。您可通过系统或浏览器设置进行管理，但可能影响部分功能。

## 三、我们如何委托处理、共享、转让、公开披露个人信息

3.1 委托处理：我们可能委托云服务、短信、定位、登录、支付、对象存储、图像识别等供应商代表我们处理信息，并要求其仅在委托范围内处理、承担保密与安全义务。  
3.2 共享：未经您同意，我们不会与第三方共享您的个人信息，但以下情况除外：获得您的明确同意；与关联方为向您提供服务所必需且受本政策约束；根据法律法规或行政/司法要求；在合并、收购、破产等情形下，如涉及转移将要求新的持有方继续受本政策约束或重新征得同意。  
3.3 公开披露：原则上不公开披露。确需披露时，会告知目的与类型并征得同意，或依据法律法规进行。

## 四、我们如何存储和保护个人信息

4.1 存储地点：您的个人信息将存储于中华人民共和国境内。如因业务需要跨境传输，将依法另行征得同意并落实合规措施。  
4.2 存储期限：我们仅在实现目的所必需的最短期限内保存；超出期限后删除或匿名化，法律法规另有规定的除外。账号注销后将按法规要求删除或匿名化处理（法律法规要求留存的除外）。  
4.3 安全措施：我们采取加密传输/存储、访问控制、权限分级、安全审计等措施。但请理解，任何安全措施都无法做到绝对安全。

## 五、我们如何保护未成年人信息

本应用主要面向成年人。若您为未满 18 周岁的未成年人，请在监护人同意与指导下使用。我们不会主动收集儿童个人信息；如发现误收集，将尽快删除。

## 六、您的权利

在符合法律法规的前提下，您对自己的个人信息享有：  
（1）查阅、复制；  
（2）更正、补充；  
（3）删除；  
（4）撤回同意（不影响撤回前基于同意的处理）；  
（5）注销账号；  
（6）获取本政策解释说明。  

您可通过应用内相关功能或本政策披露的联系方式提出请求。我们将在核实身份后依法及时处理。

## 七、第三方 SDK / 服务说明

为提供相关能力，本应用可能接入以下类型的第三方服务（名称与实际集成以版本为准）：  
（1）定位服务（如高德）：获取位置以支持水印与相关功能；  
（2）微信开放平台：微信登录与分享相关能力；  
（3）支付宝：支付与会员购买；  
（4）推送/统计/崩溃分析类 SDK（如有）：用于消息通知或稳定性分析；  
（5）云存储与内容安全/图像识别服务：用于上传存储与识别能力。  

第三方可能依据其隐私政策独立处理信息，建议您同时阅读其公示文本。
